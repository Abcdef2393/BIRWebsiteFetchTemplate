# Build Island Website Fetch
Template for Build island website fetch block.
you need to have node js and you need to deploy
the code onto a web service. A web service specifically,
not a static service, or other stuff.

You can use render.com since it is free, and
it gives you a free website to get fetch.

## DO NOT RENAME INDEX.JS, OR PACKAGE.JSON
you can delete this read.me.
if you rename main in package.js, and,  start in package.js
it may not work, because for some websites, the information
from package.json is hardwired.
